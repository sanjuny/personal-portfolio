# Sanjay Kumar M.

Personal portfolio for a full-stack software engineer. The site covers production SaaS and B2B experience, AI-assisted engineering workflows, and work that can be shown publicly.

Live site: [personal-portfolio-henna-pi-93.vercel.app](https://personal-portfolio-henna-pi-93.vercel.app)

## Run locally

```bash
npm install
npm run dev
```

## Configuration

Copy `.env.example` to `.env.local`.

- `NEXT_PUBLIC_GITHUB_USERNAME` — public GitHub username
- `NEXT_PUBLIC_LINKEDIN_URL` — full LinkedIn profile URL
- `NEXT_PUBLIC_SITE_URL` — canonical site URL, with no trailing slash

Place a resume at `public/Sanjay-Kumar-Resume.pdf` to enable the download link.
